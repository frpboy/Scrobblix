# Issue Label Taxonomy

## Type

- `type:bug`
- `type:feature`
- `type:security`
- `type:performance`
- `type:accessibility`
- `type:documentation`
- `type:research`
- `type:maintenance`

## Area

- `area:engine`
- `area:database`
- `area:lastfm`
- `area:windows`
- `area:ui`
- `area:extension`
- `area:native-host`
- `area:installer-update`
- `area:privacy`
- `area:tooling-ci`

## Priority

- `priority:critical` — security, corruption, data loss, release blocker.
- `priority:high` — major reliability or core workflow failure.
- `priority:medium` — meaningful but recoverable limitation.
- `priority:low` — polish, convenience, or deferred improvement.

## State

- `status:needs-triage`
- `status:needs-info`
- `status:ready`
- `status:blocked`
- `status:in-progress`
- `status:needs-review`
- `status:verified`

## Contribution

- `good-first-issue`
- `help-wanted`
- `breaking-change`
- `needs-adr`
- `needs-design`
- `needs-test`

Labels do not replace milestones, assignees, linked pull requests, or written acceptance criteria.
