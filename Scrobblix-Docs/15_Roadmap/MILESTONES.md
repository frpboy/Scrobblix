# Milestones

> **Project:** Scrobblix  
> **Owner:** Rahul Muraleedharan (`frpboy`)  
> **Status:** Documentation baseline  
> **Last updated:** 2026-08-01

## M0 — Foundations

Repository, docs, .NET/extension skeletons, CI, domain model, clocks, reason codes, schema/migrations, synthetic test media.

## M1 — Reliable local tracker

GSMTC adapter, canonical playback engine, eligibility, local history, Home/History/Diagnostics basics. No remote scrobbling until durability tests pass.

## M2 — Last.fm alpha

Authentication/Credential Locker, now playing, durable scrobble queue, retry/classification, queue UI, love/unlove, test-account validation.

## M3 — Browser Companion beta

Native Host, Chromium/Firefox, first site adapters, source arbitration, permissions/sources UI, installer repair.

## M4 — Product beta

Statistics, timeline, export, backup/restore, notifications, settings, accessibility, performance, signed packaging/update.

## M5 — v1.0

Compatibility matrix, security/privacy/legal review, migration/recovery, support bundle, store/release readiness, docs and release evidence.

## Post-v1

Provider plugins, additional adapters, metadata rule editor, ARM64 maturity, portable build, optional ListenBrainz, Discord presence, cross-platform research.
