# External Source Review Checklist

> **Project:** Scrobblix  
> **Owner:** Rahul Muraleedharan (`frpboy`)  
> **Status:** Documentation baseline  
> **Last updated:** 2026-08-01

When an external fact influences requirements or implementation:

- Use primary official documentation/specifications first.
- Record URL and access date.
- Distinguish normative provider/platform rule from Scrobblix recommendation.
- Verify version/applicability to supported OS/browser/runtime.
- Avoid copying long copyrighted text; summarize and link.
- Recheck terms, rate limits, browser permissions, OS lifecycle, and framework support before release.
- If sources conflict, document the conflict and conservative decision in an ADR/risk.
- Never derive legal assurance from a general web search; obtain legal review when required.
