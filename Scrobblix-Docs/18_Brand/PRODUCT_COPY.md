# Product Copy Guide

## Tagline candidates

Primary recommendation: **Your listening, reliably recorded.**

Alternatives for evaluation:

- **Know what played. Know what scrobbled.**
- **A transparent listening companion for Windows.**
- **Reliable scrobbling with answers.**

Do not finalize public copy until name clearance and positioning research are complete.

## Standard description

Scrobblix is a privacy-first Windows listening companion that detects supported desktop and browser playback, keeps a local listening history, queues eligible Last.fm scrobbles, and explains why every track was accepted, delayed, ignored, or failed.

## Status vocabulary

Use these stable user terms:

- Detected.
- Playing.
- Paused.
- Waiting for eligibility.
- Eligible.
- Queued.
- Retrying.
- Scrobbled.
- Ignored.
- Duplicate.
- Authentication required.
- Permanently failed.

Avoid vague terms such as “processed,” “done,” “issue,” or “error” without supporting detail.

## Error construction

Every error contains:

1. What happened.
2. What evidence supports the conclusion.
3. Whether data is safe.
4. What the user can do next.
5. A technical code/correlation ID when useful.

Example: “Scrobble preserved in Queue. Last.fm could not be reached after 10 seconds. Scrobblix will retry automatically when the network is available. Code: NET-TIMEOUT.”
