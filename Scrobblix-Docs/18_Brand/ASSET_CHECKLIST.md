# Brand and Release Asset Checklist

## Application assets

- Master vector logo.
- Monochrome mark.
- Windows app icon size set.
- Tray icons for light, dark, and high-contrast modes.
- Installer/package assets.
- Notification icon.
- Placeholder album artwork.
- Empty-state illustrations, if used.

## Store and repository assets

- GitHub social preview.
- README hero image or product screenshot.
- Microsoft Store/WinGet screenshots and descriptions, when applicable.
- Chrome/Edge/Firefox extension icons and store screenshots.
- Privacy disclosure images only when they clarify permission use.

## Documentation assets

- Architecture diagram export.
- Onboarding screenshots.
- Home, History, Queue, Diagnostics, Sources, and Settings screenshots.
- Annotated troubleshooting screenshots.
- Accessibility alternative text.

## Release controls

- Source design files retained in an editable open or documented format.
- Generated assets reproducible from source.
- Licence/provenance recorded for every third-party font, icon, screenshot, and artwork sample.
- No real user's listening history appears in public screenshots without explicit consent.
