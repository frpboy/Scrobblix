# Legal and API Compliance Checklist

> **Project:** Scrobblix  
> **Owner:** Rahul Muraleedharan (`frpboy`)  
> **Status:** Documentation baseline  
> **Last updated:** 2026-08-01

## Last.fm

- Register and maintain valid API account.
- Use documented APIs and authentication.
- Non-commercial use unless a commercial agreement is obtained.
- Respect rate limits and caching headers.
- Credit/link Last.fm where Last.fm data appears.
- Do not imply sponsorship/endorsement.
- Review brand/logo rules before using marks.
- Observe data limits and restrictions, including artwork/API data constraints.
- Recheck terms before every public release.

## Open-source/license

- MIT covers Scrobblix code, not third-party data, trademarks, artwork, or dependencies.
- Maintain `THIRD_PARTY_NOTICES` generated/reviewed for shipped dependencies.
- Do not distribute copyrighted album art/test media without permission; use synthetic fixtures.

## Browser stores and Windows distribution

- Permission declarations match actual use and privacy policy.
- No remote executable code in extension.
- Package identity, signing, update, and store policies reviewed at release.

## Branding

Perform name/domain/store/trademark clearance before significant promotion. “Scrobblix” should include a disclaimer that it is not affiliated with or endorsed by Last.fm.

This document is engineering guidance, not legal advice.
