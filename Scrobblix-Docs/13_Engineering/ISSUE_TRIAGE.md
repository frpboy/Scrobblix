## Labels

Type (`bug`, `feature`, `docs`, `security`, `compatibility`), area, severity/priority, source/browser/player, status, needs-reproduction, good-first-issue.

## Bug intake

Require version, Windows/browser/source, steps, expected/actual, local outcome/reason, sanitized diagnostics. Remove secrets/personal data promptly.

## Severity

- Critical: remote/local code execution, credential compromise, widespread data loss/malicious update.
- High: repeatable queue/history loss, major security/privacy breach, app unusable for supported source.
- Medium: incorrect behavior with workaround.
- Low: minor UX/docs/cosmetic.

## Compatibility

A source/site failure is not automatically core severity; assess user share, regression, data loss/false scrobble, workaround, and adapter maintenance status.
