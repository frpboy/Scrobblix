## Release matrix template

| Dimension | Required |
|---|---|
| Windows | Current supported Windows 11 Home/Pro and Enterprise baseline at release |
| Architectures | x64; ARM64 when offered |
| Browsers | Current stable Chrome, Edge, Firefox; defined previous-version policy |
| Displays | 100/150/200% scale, mixed-DPI multi-monitor |
| Themes | light, dark, high contrast |
| Install | clean, upgrade, repair, uninstall, App Installer/Store path |
| Network | online, offline, captive/failed TLS simulation, rate limit |
| Power | lock/unlock, sleep/resume, hibernate where supported |

## Source matrix

For each claimed player/site record version, detection paths, metadata fields, pause/seek/repeat behavior, multiple-session behavior, known limitations, and pass date. A marketing support claim must link to a passing matrix entry.
