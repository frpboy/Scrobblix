# Release Checklist

> **Project:** Scrobblix  
> **Owner:** Rahul Muraleedharan (`frpboy`)  
> **Status:** Documentation baseline  
> **Last updated:** 2026-08-01

## Product

- Version/scope/release notes finalized.
- All Must requirements complete/waived visibly.
- Known issues and compatibility matrix current.

## Quality

- Unit/integration/browser/UI/accessibility/security/performance suites pass.
- Long-run soak and crash/data-loss review complete.
- Migration/backup/restore tested from supported versions.

## Security/legal

- Secrets/dependencies/licenses/SBOM reviewed.
- Artifacts signed and signatures verified from clean machine.
- Last.fm terms/attribution/API key health reviewed.
- Browser permissions/privacy/store text match build.

## Distribution

- Clean install, update, repair, uninstall tested.
- Native Messaging registered/removed correctly.
- Update feed/Store/WinGet metadata and hashes correct.
- Rollback/recovery plan available.

## Operations

- Support docs, diagnostics, bundle redaction, issue templates ready.
- Release announcement avoids unsupported claims.
- Tag/release artifacts immutable and provenance retained.
