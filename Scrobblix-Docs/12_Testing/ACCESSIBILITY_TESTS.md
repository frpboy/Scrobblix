# Accessibility Tests

> **Project:** Scrobblix  
> **Owner:** Rahul Muraleedharan (`frpboy`)  
> **Status:** Documentation baseline  
> **Last updated:** 2026-08-01

## Automated

WinUI accessibility tooling, UI Automation tree checks, contrast/static analysis where supported, missing labels/automation IDs, keyboard focus traps.

## Manual required

Keyboard-only primary flows; Narrator announcements; 200% text; 150/200% display scaling; high contrast; light/dark/system; reduced motion; chart alternatives; notifications; error dialogs.

## Acceptance

No critical blockers. Every primary action has accessible name/role/state, focus visible, errors associated with controls, status not color-only, current-track updates not overly verbose.
