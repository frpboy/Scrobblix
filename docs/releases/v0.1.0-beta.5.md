# Scrobblix v0.1.0-beta.5

Unsigned Windows x64 preview. This is a development test bundle, not a signed installer or a production release.

## Local storage compatibility

Fixes a startup checksum mismatch when an existing database was created by an LF-line-ending build and a later build embeds the same SQL with CRLF line endings. Only the exact known LF and CRLF migration hashes are accepted. Changed SQL and unknown or inconsistent migration histories are still rejected.

Existing history, account references, queued actions, loved tracks and migration records are not reset or rewritten by this fix. Windows tests compare those rows before and after reopening, and the exact packaged ZIP is tested with a synthetic legacy LF database as well as a fresh profile.

A reported startup banner matches this checksum-error category, but the original stored hash has not been inspected. This release is not proof that every checksum mismatch, player-detection issue or device-specific problem is fixed. If the same error remains, keep your data intact and report the message. Do not reset or delete the database.

## Run this preview

Close Scrobblix, extract the entire Windows bundle to a new folder and run desktop/Scrobblix.Desktop.exe. Keep your existing app-data folder intact. Do not run inside the ZIP or copy just the EXE. Private .NET and Windows App SDK runtimes are included. Do not disable security protections if Windows blocks this unsigned preview.

No Last.fm credentials or hosted backend are included. This change does not configure Last.fm or change its authorization requirements. The optional browser companion remains a development package.
